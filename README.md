## 📌 Project Overview

This project focuses on applying basic probability and statistics concepts to a dataset of 200 students.

The dataset contains information about:

- Study hours per week
- Attendance percentage
- Group discussion participation
- Previous test score
- Final exam result

The main purpose of this project is to understand probability concepts and apply them to real-world student data.

---

## 📊 Dataset

The dataset contains 200 student records with the following columns:

| Column | Description |
|---|---|
| `study_hours` | Number of hours a student studied per week |
| `attendance` | Percentage attendance in lectures |
| `group_discussion` | Participation in group discussions (`Yes`/`No`) |
| `previous_test_score` | Marks out of 100 from the previous internal test |
| `final_exam_pass` | Final exam result (`Pass`/`Fail`) |

# 1. 🎲 Understanding Probability

## What is Probability?

Probability represents the chance or likelihood of an event occurring.

The value of probability always lies between 0 and 1.

- `0` → Impossible event
- `1` → Certain event
- `0.5` → 50% chance

### Example from the Dataset

There are 200 students in the dataset.

70 students passed the final exam.

Therefore:

```text
P(Pass) = Number of students who passed / Total students

P(Pass) = 70 / 200

P(Pass) = 0.35
